## Uso y actualización

El funcional define el alcance; el anexo aporta precisiones técnicas; la guía v2 reemplaza la v1. La v1 se enlaza solo como histórico: no usar sus instrucciones sustituidas. La [base del proyecto](../requisitos/base-proyecto.md) registra la planificación y las decisiones pendientes. Las fechas históricas de los originales no sustituyen el inicio confirmado del 15 de octubre ni la salida tentativa del 15 de noviembre de 2026.

Drive conserva la fuente documental. La copia técnica de GitHub no se sincroniza automáticamente: cuando el original cambie, revisar las diferencias y actualizarla en un commit, sin incorporar credenciales ni enlaces de secretos.

Los documentos de acceso Mercately y Shopify quedan excluidos del índice y del repositorio. No guardar tokens, contraseñas ni enlaces de un solo uso. Mantener el repositorio privado y respetar el NDA.
